# Projet QuestAR
Jeu mobile AR (Unity 6 + AR Foundation, cible Android/ARCore).
Ma tâche : Partie 5 « Résous les énigmes et progresse » : panneau holographique avec cadenas, code à 4 chiffres dont les indices flottent autour du joueur. Bon code = indice "La crypte du château renferme le plan" + 50 XP.

## Règles
- Je suis débutant : explique simplement, en français.
- Scripts dans Assets/QuestAR/Scripts/, prefabs dans Assets/QuestAR/Prefabs/, scènes dans Assets/QuestAR/Scenes/
- Code simple et commenté en français.
- Après chaque modification, vérifie la console Unity et corrige les erreurs.
- Style : hologrammes bleu cyan (#00C8FF), sci-fi.
- Thème : jeu d'horreur de vampires, rouge (#B00020) et noir (#0A0A0A), blanc os (#EDE6DA)

## Configuration obligatoire (ne jamais modifier)
- Plateforme Android, Google ARCore coché (onglet Android)
- Graphics APIs : OpenGLES3 uniquement (pas de Vulkan)
- Minimum API Level 26, IL2CPP, ARM64 uniquement


## Économie de tokens (prioritaire)
- Réponses courtes : 5 lignes maximum, sauf si je demande plus.
- Ne jamais attendre ni surveiller Unity en boucle (pas de moniteur, pas de nouvelles tentatives répétées). Si Unity est occupé ou déconnecté, dis-le-moi en une ligne et arrête-toi.
- Ne lis que les fichiers nécessaires à la tâche.
- Pas de résumé détaillé à la fin : juste ce qui a été créé et ce que je dois tester.
- Si une erreur persiste après 2 essais, arrête-toi et montre-moi l'erreur.
